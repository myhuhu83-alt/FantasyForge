# FantasyForge 奇幻命名宝库

## 项目简介

FantasyForge 是一个奇幻世界观命名参考工具，包含436条精心整理的武器、怪兽、英雄、城市、技能、天赋、势力数据。

**数据来源**：魔兽世界、暗黑破坏神、指环王、英雄无敌、宠物小精灵、艾尔登法环、刀塔2、英雄联盟等经典IP，以及原创内容。

## 功能说明

### 🔍 搜索功能
- 支持搜索名称、来源、描述
- 实时过滤，无需点击按钮

### 📂 分类筛选
- 全部 / 武器 / 怪兽 / 英雄 / 城市 / 技能 / 天赋 / 势力
- 显示每个分类的数据条数

### ⚡ 元素筛选
- 火 / 冰 / 电 / 暗 / 光 / 格斗 等18种元素
- 支持多选组合筛选

### 🎲 随机灵感
- 从当前筛选结果中随机选择一条
- 高亮显示3秒

### 📋 卡片复制
- 点击任意卡片自动复制详细信息
- 格式：名称 + 来源 + 等级 + 属性 + 描述

### 🗺️ 世界地图（仅完整版）
- 6个世界层级可切换
- 鼠标悬停查看城市/势力详情
- 支持势力分布查看

## 常见问题

**Q: 为什么双击HTML文件后页面空白？**
A: 某些浏览器可能限制本地文件访问。请使用版本1（index.html）或启动本地服务器。

**Q: 如何添加新数据？**
A: 编辑 `data.js` 或 `full_db.js`，添加符合格式的新条目。格式参考现有数据。

**Q: 地图功能在精简版中为什么没有？**
A: 精简版为提升加载速度移除了地图模块，请使用完整版（index.html）查看地图。
